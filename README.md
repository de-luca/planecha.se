# Planecha.se

> A Planechase *thingy* for people playing over the internet (or not).

## Install & Dev

### Building card assets and data
```sh
brew install imagemagick
./planar_extraction.sh
```

### Setup project

Install dependencies:
```sh
bun install
```

Start dev server:
```sh
bun dev
```
